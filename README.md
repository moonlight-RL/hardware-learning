# Hardware Learning

从零开始的嵌入式硬件学习记录：26 周，每周约 10 小时，目标是能独立完成嵌入式项目，并为实验室机械臂开发控制层与边缘 AI 交互功能。

## 学习目标

- 掌握电子电路基础（模电/数电），会用万用表、Multisim 验证电路
- 掌握 STM32 开发：GPIO、定时器/PWM、ADC、串口、I2C、中断、FreeRTOS
- 完成 4 个实战项目：调光控制器 → 机械臂控制层 → 自制开发板 → 手势/语音控制机械臂
- 最终产出：3–4 个完整项目、GitHub 作品集、简历

## 安全守则

- 所有 LED 必须串联限流电阻，禁止直接接 3.3V/5V
- 烧录前确认供电方式唯一（ST-Link 或 USB 二选一）
- CubeMX 工程必须开启 Serial Wire Debug，避免 SWD 锁死
- 观察实验室机械臂须先征得同意，不通电、不改接线
